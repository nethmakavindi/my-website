# My Website

A simple website created using HTML and CSS.

## About the Project

This project is a basic website that displays a heading, a welcome message, and a button.

## Technologies Used

- HTML5
- CSS3

## Features

- Displays a "Hello World!" heading.
- Shows a welcome message.
- Includes a "Click Me" button.
- Uses an external CSS file for styling.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
